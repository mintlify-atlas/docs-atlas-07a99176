CF2CNP (Cilium Flow to CiliumNetworkPolicy) eliminates the tedious manual work of writing Kubernetes network policies. Point it at Hubble flow data — captured from real traffic in your cluster — and it produces accurate `CiliumNetworkPolicy` YAML files, complete with ingress/egress rules, cross-namespace labels, FQDN egress with DNS resolution, and port specifications.

## How It Works

<Steps>
  <Step title="Capture flows with Hubble">
    Export network flow data from your cluster using the Hubble CLI or the [hubble-observer](https://github.com/onzack/hubble-observer) Helm chart.

    ```bash
    hubble observe --namespace my-app --output json > flows.json
    ```
  </Step>
  <Step title="Run CF2CNP">
    Pass the directory containing your flow JSON files. CF2CNP parses, aggregates, and generates a policy file per workload.

    ```bash
    cf2cnp generate --input ./flows --output ./policies
    ```
  </Step>
  <Step title="Review and apply">
    Inspect the generated YAML files, then apply them to your cluster.

    ```bash
    kubectl apply -f ./policies/
    ```
  </Step>
</Steps>

## Key Features

<CardGroup cols={2}>
  <Card title="Smart Label Filtering" icon="filter">
    Extracts only the most relevant Kubernetes app labels (`app.kubernetes.io/name`, `app`, etc.) to keep policies clean and maintainable.
  </Card>
  <Card title="FQDN Egress Rules" icon="globe">
    Automatically generates `toFQDNs` rules with the required DNS resolution egress rule for external traffic.
  </Card>
  <Card title="Cross-Namespace Support" icon="arrows-left-right">
    Adds `io.kubernetes.pod.namespace` labels when source and destination live in different namespaces.
  </Card>
  <Card title="Flow Aggregation" icon="layer-group">
    Combines multiple flows with the same source/destination into a single policy with multiple port entries.
  </Card>
  <Card title="HTTP Server Mode" icon="server">
    Run as a containerized service. Generate policies via REST API or the built-in Web UI, with Grafana integration support.
  </Card>
  <Card title="Helm Deployment" icon="helm" href="/deployment/helm">
    Official Helm chart available from the OCI registry for fast in-cluster deployment.
  </Card>
</CardGroup>

<Warning>
  CF2CNP was built with AI assistance. Always review generated policies carefully before applying them to production clusters. The tool provides a strong starting point, but human review is essential for security-sensitive environments.
</Warning>
